# Data summary text for the manuscript

Replace bracketed fields after the sequence accessions and repository DOI are available.

> Raw sequencing reads for *Parasarocladium* sp. MA12 have been deposited in the NCBI Sequence Read Archive under accession [SRR...], associated with BioProject [PRJNA...] and BioSample [SAMN...]. The whole-genome shotgun assembly has been deposited in DDBJ/ENA/GenBank under accession [ACCESSION], and the version described in this article is [VERSION]. The scripts, workflow documentation, and analysis parameters used for genome assembly, quality assessment, annotation, phylogenomics, and comparative genomics are available from GitHub at [GITHUB URL] and have been archived in Zenodo under DOI [DOI]. Supporting output tables are provided with the article as supplementary data. The authors confirm that all supporting data, code and protocols have been provided within the article, through supplementary data files, or in the repositories listed above.

## When the GitHub repository has no DOI yet

Use the GitHub URL during drafting, but archive the exact release in Zenodo or another repository before final publication. A DOI is preferable because it points to an immutable version of the code rather than the changing default branch.
