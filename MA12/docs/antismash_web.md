# antiSMASH web analysis

Biosynthetic gene clusters were predicted with antiSMASH v8.0 using the web server.

## Recommended reproducibility record

For the final public release, record:

- antiSMASH version: 8.0;
- submission date;
- input file name and checksum;
- whether the input was nucleotide FASTA or annotated GenBank;
- all selected web options;
- downloaded result archive name;
- checksum of the downloaded archive.

## Input

The annotated genome assembly should be submitted in GenBank format whenever available so that predicted coding sequences are retained.

## Output

The complete antiSMASH result archive should be preserved outside GitHub if it is large. Recommended deposition options are:

- supplementary data;
- Zenodo release;
- institutional data repository.

The GitHub repository may include compact summary tables and scripts used to compare BGC counts, but should not contain unnecessarily large interactive HTML result directories.
